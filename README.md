## 🚀 Featured Projects

### 🤖 [ResearchCrew — Multi-Agent Research System](https://github.com/surya-aiml20/multi-agent-research-assistant)
A multi-agent assistant that **plans, retrieves, critiques and reports** autonomously. Combines live web search with PDF RAG and a **critic-driven loop** that detects evidence gaps and re-researches them, producing source-cited reports.
`Python` `CrewAI` `Groq` `Serper API` `ChromaDB` `BGE Embeddings` `PyMuPDF` `Streamlit`

### 🏛️ [CivicAI — Legislative Intelligence Platform](https://github.com/surya-aiml20/Legislative-Watchdog-)
Transforms unstructured legislative documents into **searchable intelligence** using RAG, semantic search and LLM summarization — a complete pipeline from ingestion to an interactive AI interface.
`Python` `LLMs` `RAG` `Vector Embeddings` `Apache Airflow` `Supabase` `Streamlit`

### 🫁 [PneumoniaAI — Pneumonia Detection System](https://github.com/surya-aiml20/PneumoniaAI-AI-Powered-Pneumonia-Detection-System)
A CNN-based system detecting pneumonia from chest X-rays with **89%+ accuracy**, deployed as a **Django web app** for real-time image upload and AI-assisted prediction.
`Python` `TensorFlow` `CNN` `Scikit-learn` `Django`

### 📊 [AI Data Analyst](https://github.com/surya-aiml20/ai-data-analyst) · 💬 [Local DeepSeek-R1 Chatbot](https://github.com/surya-aiml20/Chatbot-with-DeepSeek-R1-Ollama-Streamlit)
